# Propósito del proyecto:

Testear el correcto funcionamiento de la web https://www.saucedemo.com , contemplando el proceso de Login, navegación y verificación del catálogo y la interacción con productos.


## 🛠️ Tecnologías utilizadas
- Python como lenguaje principal
- Pytest para estructura de testing
- Selenium WebDriver para automatización
- Git y GitHub para control de versiones

## 📦 Instalación
1. Clona el repositorio:
   ```bash
   git clone https://github.com
   ```
2. Instala las dependencias:
   - Desde la terminal "pip install selenium"
   - Desde la terminal "pip install webdriver-manager"
   - Desde la terminal "pip install pytest"

## 🚀 Comando para ejecutar las pruebas
"pytest -v --html=reportes/reporte.html"
